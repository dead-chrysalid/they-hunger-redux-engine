## About

This is the They Hunger Redux development of [sultim-t/xash-rt](https://github.com/sultim-t/xash-rt). Its upstream and mod development history retain the original contributors' attribution. 

## Build

Use the main project's `sources.json` and Windows source-only build workflow to obtain the matching engine, SDK, renderer, and menu revisions. Client API **10** and renderer API **4** are the coordinated interfaces.

The mod's resource collection and playable downloads are distributed separately through ModDB. The main project will add its ModDB link when the page is published.

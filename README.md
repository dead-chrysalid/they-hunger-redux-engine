# They Hunger Redux — Engine

The Xash RT engine used by They Hunger Redux, based on [Sultim's Xash RT](https://github.com/sultim-t/xash-rt).

## Build

Build the matching components together using the main project's [Windows build guide](https://github.com/dead-chrysalid/they-hunger-redux/blob/master/docs/BUILDING.md).
